# Freelancer CRM Client List

This Python script provides a simple, file-based CRM for freelancers to manage client information. It allows adding, listing, finding, and updating client details, storing data in a JSON file to avoid external dependencies.

## Language

`python`

## How to Run

Save the code as `freelancer_crm.py` and run it from your terminal using `python freelancer_crm.py`. A `clients.json` file will be created in the same directory.
